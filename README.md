# The Poem About Permission

A short poem about agency — the power to ask and to be given — told through doors, a spare key in a chipped teacup, and the weight of a yes or a no. Running `main.py` writes the poem to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
